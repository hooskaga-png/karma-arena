# KARMA ARENA

A premium, mobile-first global sports gaming platform prototype inspired by modern football and esports dashboards.

## Features
- Responsive dashboard and navigation
- 1v1 football challenge flow
- Tournaments, sports fixtures, wallet and leaderboard screens
- Friend management and notifications
- Admin dashboard and support center
- International-ready currency and country configuration

## Stack
- Next.js
- React
- Tailwind CSS
- lucide-react

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000
